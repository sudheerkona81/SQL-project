**Project Description**

This project focuses on managing student information using SQL. The main objective is to create a Students table containing student ID, name, city, course and marks. Ten student records are inserted into the table, and SQL queries are executed to retrieve and analyse the data.

The project uses PostgreSQL and DB Fiddle (online SQL editor) to perform basic database operations such as CREATE TABLE, INSERT, SELECT, WHERE, ORDER BY, GROUP BY, COUNT and AVG.

**Outcome:** Successfully created a student database, retrieved records based on conditions, sorted student marks, calculated course-wise student counts and determined the average marks.
